The official block theme for Flourish Integrated Health, a women's health clinic in Edmonton, Alberta, built on the Flourish Brand Style Guide (2026).

== Description ==

Flourish is a full-site-editing block theme built for the Gutenberg Site Editor. All colours, fonts, spacing and
block styles live in theme.json, so they can be changed under Appearance → Editor → Styles without code.

Includes:
* Templates: front page, blog, single post, page, archive, search, 404, Landing Page (no title) and Page with Booking Sidebar.
* Template parts: header (sticky, with mobile menu), footer, announcement bar.
* Patterns (Flourish category): hero, values bar, services grid, welcome image and text, how-it-works steps,
  mission statement, care team, FAQ, location and hours, waitlist call to action, page header, posts grid.
* Full-page patterns: Home, Services, About, Contact.
* Block styles: Card, Rounded panel, Arch image, Subheader (Poppins caps), Lead, Accent (Cormorant italic), Checkmark list, Soft button, Monogram separator.
* Brand palette: Earth, Clay, Terra, Dune, Blush, Cream, Pearl, White (+ accessible text tints of Clay and Terra).
* Official Flourish logo suite (primary, wordmark, brand mark, monogram, lettermark, text mark) as SVG in Earth, Clay and White.
* Self-hosted brand fonts (no Google Fonts requests): Marcellus, Poppins, Cormorant Garamond Italic.
